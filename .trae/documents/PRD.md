# 视频分享平台 - 产品需求文档 (PRD)

## 1. 项目概述

### 项目名称
**VidHub** - 一个现代化的视频分享平台

### 项目类型
Web 端视频分享网站（类似哔哩哔哩）

### 核心功能摘要
一个具有弹幕功能、视频播放、UP主投稿、用户互动（点赞、投币、收藏）、分区导航、搜索推荐等核心功能的视频分享社区平台。

### 目标用户
- 视频内容消费者（观众）
- 视频内容创作者（UP主）
- 社区互动用户

---

## 2. 功能需求

### 2.1 首页模块
- **顶部导航栏**：Logo、搜索框、用户头像/登录入口、分区导航
- **轮播图区域**：展示热门/推荐视频内容
- **分区入口**：动画、番剧、音乐、游戏、科技、生活、娱乐、影视等分区
- **视频列表**：推荐视频、热门视频、近期更新列表
- **页脚**：版权信息、链接

### 2.2 视频播放页
- **视频播放器**：支持播放、暂停、音量控制、全屏
- **弹幕系统**：实时弹幕显示、弹幕开关、弹幕透明度调节
- **视频信息**：标题、UP主信息、播放量、点赞、投币、收藏数
- **互动区域**：点赞、投币、收藏、分享按钮
- **评论区**：楼层评论、回复功能
- **相关推荐**：同分区相关视频推荐

### 2.3 搜索功能
- **搜索框**：支持关键词搜索
- **搜索结果页**：视频列表、播放量排序、发布时间排序
- **搜索建议**：热词推荐、搜索历史

### 2.4 分区页面
- **分区标题**：分区名称、简介
- **筛选排序**：最新发布、最多播放、最多收藏
- **视频列表**：瀑布流/网格布局

### 2.5 用户中心
- **用户信息**：头像、昵称、等级、签名
- **投稿管理**：已投稿视频列表
- **收藏夹**：用户收藏的视频列表
- **历史记录**：观看历史

## 3. UI/UX 设计方向

### 3.1 整体视觉风格
- **主题**：深色主题为主，呼应主流视频平台风格
- **风格**：现代简约、科技感、年轻化
- **配色**：深蓝/深紫为主色调，粉紫色为强调色

### 3.2 色彩方案
- **主色**：#00A1D6（哔哩蓝）/ #FB7299（粉色强调）
- **背景色**：#1A1A2E（深色背景）
- **卡片色**：#252540（卡片/容器背景）
- **文字色**：#FFFFFF（主文字）、#99A2B8（次要文字）
- **强调色**：#FFD700（金币色）、#FF6B6B（点赞红）

### 3.3 布局风格
- **整体布局**：左窄右宽（导航栏固定左侧+内容区）
- **响应式**：桌面端优先，支持平板和移动端适配
- **卡片设计**：圆角卡片、hover 阴影效果
- **动效**：页面切换渐变、hover 过渡动画

### 3.4 字体
- **标题**：思源黑体 / Noto Sans SC Bold
- **正文**：思源黑体 / Noto Sans SC Regular
- **数字/英文**：Inter

## 4. 技术架构

### 4.1 技术栈
- **前端框架**：React + TypeScript
- **构建工具**：Vite
- **样式方案**：Tailwind CSS
- **状态管理**：Zustand
- **路由**：React Router v6
- **图标**：Lucide React

### 4.2 项目结构
```
src/
├── components/      # 通用组件
├── pages/           # 页面组件
├── hooks/           # 自定义 Hooks
├── store/           # Zustand 状态管理
├── utils/           # 工具函数
├── assets/         # 静态资源
└── types/          # TypeScript 类型定义
```

### 4.3 数据模拟
- 使用本地 Mock 数据模拟视频信息、UP主信息、评论等
- 视频封面和缩略图使用 placeholder 服务

---

## 5. 页面清单

1. **首页 (Home)** - `/` - 主页展示、轮播图、分区入口、视频列表
2. **分区页 (Category)** - `/category/:id` - 特定分区的视频列表
3. **视频播放页 (Watch)** - `/watch/:id` - 视频播放、弹幕、评论
4. **搜索页 (Search)** - `/search` - 搜索结果展示
5. **用户中心 (User)** - `/user/:id` - 用户信息、投稿、收藏

---

## 6. 优先级

### P0 - 核心功能
- 首页布局和导航
- 视频播放页
- 基础视频列表

### P1 - 重要功能
- 弹幕系统
- 搜索功能
- 点赞/投币/收藏交互

### P2 - 增强功能
- 用户中心
- 评论系统
- 历史记录

---

## 7. 验收标准

- [ ] 首页正常加载，显示轮播图和视频列表
- [ ] 点击视频能跳转到播放页
- [ ] 视频播放器基本功能正常（播放/暂停/音量/全屏）
- [ ] 弹幕可以开关和调节透明度
- [ ] 搜索能返回结果
- [ ] 页面在不同尺寸下有合理的响应式布局
- [ ] 整体视觉风格统一、年轻化、有科技感
