# Minecraft Server Manager

A comprehensive web-based management platform for Minecraft servers.

## Features

- 🎮 Server status monitoring
- 👥 Player management
- ⚙️ Server configuration
- 📊 Real-time statistics
- 📜 Console logs

## Getting Started

```bash
# Install dependencies
npm install

# Start backend server
npm run server

# Start frontend
npm run dev
```

## API Endpoints

- `/api/server/status` - Get server status
- `/api/server/start` - Start server
- `/api/server/stop` - Stop server
- `/api/server/restart` - Restart server
- `/api/players` - Get online players
- `/api/console` - Get console logs

## Tech Stack

- React + TypeScript
- Fastify
- SQLite
- Tailwind CSS
